使用说明

界面结构：顶部是菜单栏——文件（导入图、新建、保存/载入、导出）、房间（邀请、人员、昵称、换房间、离开）、视图（网格、图层、缩放）、帮助；左上角是画图工具；右侧面板分「地图 / 棋子 / 人员」三页。

1. 放一张地图：点「文件 → 导入背景图」，选择本地图片；也可以直接把图片拖到画布上。没有图片时，整块网格就是战场。

2. 对齐网格：导入后网格会自动按图片宽度取整对齐。如果格子对不上，用右侧「格子大小」微调，直到和图上格子重合。

3. 放棋子：点「＋ 添加棋子」，棋子会落在视野中央；用「选择移动」工具拖动即可，默认吸附到格子中心（按住 Alt 可自由摆放）。右侧可改名称、颜色、尺寸（1×1 ~ 4×4）和头像。

4. 做标注：左侧选择画笔 / 直线 / 矩形 / 圆形 / 文字，在地图上画陷阱、法术范围、房间名等；「橡皮」点一下就删除那一条标注。

5. 保存与导出：「保存工程」会把图片、网格、标注、棋子一起存成 .json，下次「载入工程」继续编辑；「导出 PNG」得到一张可发给玩家的地图图片。编辑内容也会自动保存在本浏览器中。

6. 分享给别人（同一 WiFi）：把 index.html 这个文件发给朋友，对方双击用浏览器打开即可；同一 WiFi 想一起看，双击 启动网站（局域网）.bat，把窗口里显示的局域网地址发给他们。

7. 跨网络多人共享同一张地图：双击 启动并分享到公网.bat，等窗口出现 https://xxx.trycloudflare.com 这样的公网链接（已自动复制到剪贴板），把它发给任何网络的朋友即可。大家打开就是同一个房间，棋子、标注、背景图、网格实时同步。

8. 房间与人员：点右上角房间按钮或「房间」菜单，可以看房间号、邀请朋友、修改我的昵称、用当前地图新建房间、离开房间；右侧「人员」页能看到每个人的昵称、颜色、权限（房主 / 编辑 / 观众）和在线状态。

9. 房主 / 观众 / 定位：第一个进房间的人是房主，房主可在人员页把别人设为只读观众（对方只能看，不能改）或踢出房间。点棋子列表里的「定位」或属性里的「定位到棋子」，视图会立刻跳到那个棋子。有人拖动棋子时，其他人会看到该棋子外圈变成对方颜色并显示「某某 移动中」。

10. 地图范围：右侧「地图」页的「地图范围」限定可编辑区域（格数），超出范围会被拉回，镜头也被限制在范围内，避免各自跑到很远的地方编辑。导入背景图时范围会按图片自动设置。

11. 地图操作（参考高德）：右下角 ＋ / − 缩放、全图 回到整体视图，双击画布也能放大；左下角显示鼠标所在的格坐标、比例尺（当前 1 格 ≈ 多长）和缩放百分比；右下角小地图显示整张地图与当前视野框，点击或拖动可快速跳转（视图菜单可关闭）。

12. 测量尺与范围：左侧「测量」里有 测距（拖一条线，显示两端距离，1 格 = 5 尺）、圆形、矩形（拖出范围，显示半径/长宽与面积，单位格²）。起点或终点靠近棋子会自动吸附并显示棋子名，棋子移动时数字会实时跟着变化。测完按 Esc 或「视图 → 清除测量」清除；按住 Alt 拖动可关闭吸附。

快捷键：V 选择 B 画笔 L 直线 R 矩形 O 圆形 T 文字 E 橡皮 M 测距 空格+拖动 平移 滚轮 缩放 Delete 删除选中棋子 Ctrl+Z 撤销 Ctrl+S 保存工程
